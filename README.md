# Moder-Basic-Calculator
A modern dark-themed calculator built with HTML, CSS &amp; JavaScript

## 🔗 Live Demo
[Click here](https://PratoolGit.github.io/Modern-Basic-Calculator.html)

## ✨ Features
- Basic arithmetic (+, −, ×, ÷)
- Percentage and sign toggle
- Expression history display
- Keyboard support
- Responsive dark UI

## 🛠 Tech Stack
- HTML5
- CSS3 (animations, CSS variables)
- Vanilla JavaScript
